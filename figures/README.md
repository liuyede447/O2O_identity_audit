# Figure materials

This repository includes source data, deterministic plotting code, validation records and rendered outputs for Figures 2--6. Figures 1 and S1 use licensed benchmark pixels and are intentionally not redistributed here. Their evidence-only JSON/CSV records remain included so identities and hashes can be audited without redistributing images. Obtain the benchmark data from the official sources before rebuilding image-bearing panels.

The files under `rendered/` are release-candidate previews, not a substitute for the publisher's production files. All quantitative values trace to `../evidence/final_evidence_v4/` and the figure evidence manifest.
